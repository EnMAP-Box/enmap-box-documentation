.. _roadmap:

=======
Roadmap
=======

The AAAA development of the EnMAP-Box is based on the following schedule.
Note that from EnMAP-Box version 3.12 on, we ensure compatibility
to run with the current QGIS Long Term Release (LTR) and QGIS Latest Release (LR) according to the
`QGIS roadmap <https://qgis.org/resources/roadmap/>`_.

.. role:: strike

.. list-table::
   :header-rows: 1
   :stub-columns: 1

   * - Version
     - Minimum QGIS version
     - Planned Release Date
   * - EnMAP-Box 3.15
     - QGIS 3.34 LTR
     - End September 2024
   * - EnMAP-Box 3.16
     - QGIS 3.40 LTR
     - End Mar 2025
   * - EnMAP-Box 3.17
     - QGIS 3.40 LTR
     - End September 2025
   * - :strike:`EnMAP-Box 3.18`
     - QGIS 3.44 LTR
     - End Mar 2026
   * - :strike:`EnMAP-Box 3.19`
     - QGIS 3.44 LTR
     - End September 2026
   * - EnMAP-Box 4.0
     - QGIS 4.0 LR
     - November 2027

.. note::

    Versions 3.18 and 3.19 were skipped in favor of direct development of
    EnMAP-Box 4.0. To that end, additional updates have been released for version 3.17. The current version for QGIS 3 is `EnMAP-Box 3.17.9 <https://plugins.qgis.org/plugins/enmapboxplugin/version/3.17.9/>`_
